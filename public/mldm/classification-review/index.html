W5 · How sure are we? Intervals, CV and grid cost

≈ 6 min · L10a
  1. A tree makes 18 errors on 120 test records. Give the 95% interval for the true error with f ± z√(f(1−f)/N). Repeat with 72 errors on 480 records (same f). What changed?
  2. 5-fold CV accuracy (mean ± std) for max_depth 1 to 6 is: 84.0 ± 1.5 · 87.9 ± 1.0 · 89.0 ± 0.9 · 89.4 ± 0.8 · 88.8 ± 1.1 · 86.5 ± 1.6. Which depth does the 1-std rule choose?
  3. You search max_depth {3, 5, 8} × min_samples_leaf {1, 5} × criterion {gini, entropy} with 5-fold CV and refit the best model. How many trainings?
  4. Why not pick the depth by the accuracy on the test set?
Show model answer

1. f = 0.15, z = 1.96. N = 120: half-width = 1.96·√(0.15·0.85/120) = 0.064, interval [8.6%, 21.4%] (Wilson: [9.7%, 22.5%]). N = 480: half-width = 0.032, interval [11.8%, 18.2%]. Four times the data halves the width (1/√N).

2. Best is depth 4 (89.4, std 0.8), so the threshold is 89.4 − 0.8 = 88.6. Depths within it: 3 (89.0), 4, 5 (88.8). Depth 2 (87.9) is out. The simplest is depth 3.

3. 3 × 2 × 2 = 12 configurations; 12 × 5 + 1 = 61 trainings.

4. Choosing by the test score makes it optimistic (the winner’s curse), so it is no longer an honest estimate of run-time error. Choose with CV on the training part; use the test set once at the end.

Weak spots

Five ideas that are easy to get wrong on first reading. Outside the timed hour: use it before the exam. Read the fix, then answer the check in the box and open the answer.

1 · After cross-validation, what is the final model?

L10a

The confusion. k-fold CV trains k models, so “which one do I keep?”. Answer: none of them. CV is a measurement, not a model factory.

The fix. (1) For each configuration, run k-fold CV on the training part and record the mean score. (2) Pick the best configuration (or the simplest within 1 std). (3) Retrain that one configuration once on all the training data. That is the deliverable. (4) Score it once on the test set. The k fold models are thrown away. Count: c configurations × k folds + 1 final training.

Check. 3 values of max_depth × 2 criteria, 4-fold CV, then the final fit. How many trainings, and which model do you hand over?

Show answer

6 configurations × 4 folds = 24, plus 1 final = 25 trainings. You hand over the last one: the best configuration, retrained on all training data, whose test score you measure once.

2 · Target leakage: “days since last buy” at the root

L09

The setup. Pick a snapshot date, say 1 Jan. The label is “no purchase in the 90 days after 1 Jan”. The features must describe what you knew on 1 Jan, because that is the moment you will use the model.

The leak. If “days since last buy” is computed with today’s data (after the 90 days), a customer who did not buy in Jan–Mar automatically has a large value. The feature contains the label, so the tree finds a huge IG and a one-split stump. Computed as of 1 Jan (“40 days since the last purchase before 1 Jan”) it is a legitimate feature.

The test. At the exact moment I will use the model, can I compute this value? If not, it leaks.

Check. Snapshot 1 Jan, label = churn in Jan–Mar. Which features leak? (a) days since last purchase as of 1 Jan · (b) days since last purchase measured on 31 Mar · (c) number of purchases in Jan–Mar · (d) tenure in years at 1 Jan · (e) average basket over the whole year.

Show answer

Leak: (b), (c) and (e): all use information after 1 Jan, and “no purchases in Jan–Mar” is the label itself in (c). Fine: (a) and (d), computable on 1 Jan.

3 · κ and MCC: improvement over guessing

L10b

The problem. “Nobody churns” has 88% accuracy when 12% churn. Accuracy ignores how easy the task is.

κ. κ = (correct − correct by chance) / (perfect − correct by chance). “Correct by chance” = what a random classifier with the same predicted proportions gets: for each class, (true count × predicted count) / N, summed. NordicMart: churners 108 × 54 / 900 = 6.5, stayers 792 × 846 / 900 = 744.5, total 751. The tree gets 790, so κ = 39/149 = 0.26. “Nobody churns” gets exactly the chance level, so κ = 0.

MCC = (TP·TN − FP·FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN)): the correlation between prediction and truth, from −1 to 1, 0 at chance. NordicMart: 17,568 / 62,511 = 0.28.

Check. 1000 records, 50 positives. TP 20, FN 30, FP 20, TN 930. Accuracy is 0.95, the same as “always negative”. Compute κ and MCC.

Show answer

True positives 50, predicted positives 40. Chance: 50·40/1000 = 2 and 950·960/1000 = 912, total 914. Correct = 950. κ = (950 − 914)/(1000 − 914) = 36/86 = 0.419.

MCC = (20·930 − 20·30) / √(40·50·960·950) = 18,000 / 42,708 = 0.421. Same accuracy as the baseline, but real signal; the baseline would have κ = MCC = 0.

4 · Cumulative gains and lift

L10b

What you sort. The test customers (we know who really churned), from the highest model score to the lowest. Positive = really churned. Then ask: if I contact only the top x%, what do I catch?

Gains = % of all churners found in the top x% (random contact: the diagonal, x% for x%). Lift = gains / x = “how many times better than random”. Lift is highest at the top and falls to 1 at 100%. Only the order matters, not the score values.

Check. 8 customers sorted by score, P = churner: P P N P N N N N (3 P, 5 N). Gains and lift at the top 25% and at the top 50%?

Show answer

Top 25% = 2 customers (P P): 2 of 3 churners = 67%, lift 0.67/0.25 = 2.67. Top 50% = 4 customers (P P N P): 3 of 3 = 100%, lift 1.00/0.50 = 2.0.

5 · Drawing a ROC curve, and what you read from it

L10b

Axes. x = false positive rate = FP / (number of negatives), the share of stayers flagged by mistake. y = true positive rate = TP / (number of positives) = recall. One threshold = one point; lowering the threshold walks down the sorted list.

Drawing. Sort by score, highest first. Start at (0, 0). Next customer is a churner: step up by 1/#positives. A stayer: step right by 1/#negatives. End at (1, 1). Ties: one diagonal step.

Reading it. Up first means churners are ranked on top: a curve that hugs the top-left corner is good, the diagonal is random guessing. AUC = area under the path = the probability that a random churner is scored above a random stayer.

Check. 8 test customers sorted by score, P = churner: P P N P N P N N (4 P, 4 N). (a) List the points of the path. (b) Compute the AUC. (c) Which point do you get by flagging the top 4?

Show answer

(a) Steps are 1/4 up and 1/4 right: (0,0) → (0,.25) → (0,.5) → (.25,.5) → (.25,.75) → (.5,.75) → (.5,1) → (.75,1) → (1,1).

(b) For each stayer, the TP rate when its step right happens: 0.5, 0.75, 1, 1. AUC = (0.5 + 0.75 + 1 + 1) / 4 = 0.8125. Check by pairs: 13 of the 16 (churner, stayer) pairs have the churner ranked higher: 13/16 = 0.8125.

(c) Top 4 = P P N P: TP = 3, FP = 1, so TP rate 0.75 and FP rate 0.25: the point (0.25, 0.75).
